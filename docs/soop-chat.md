# SOOP 다시보기 채팅 검수

`/apps` → **SOOP 채팅 부검** (`/soop-chat`). 생방송 입력·연결·수집 기능은 제거했으며 다시보기만 지원합니다. 이전 브라우저의 생방송 저장 데이터는 삭제하지 않고 목록에서 숨깁니다.

## 사용

1. 공개 다시보기 주소를 입력하고 **채팅 가져오기**를 누릅니다. SOOP이 제공하는 파일들을 300초 단위로 가져오며 중단된 기록은 이어받을 수 있습니다.
2. 아이디·닉네임·내용 검색, 사용자 선택, 시간 범위(분:초 또는 시:분:초), 메시지 종류를 조합합니다. 원문과 당시 닉네임, 아이디, 영상 시간, 추정 날짜·시각을 확인할 수 있습니다.
3. **발언 검수**에서 Gemini 또는 ChatGPT · OpenAI를 선택하고 해당 제공사의 API 키를 입력합니다. 현재 검색 결과 또는 가져온 전체를 선택하고 검수 기준을 적습니다. 실행 전 대상 수와 예정 요청 수를 표시합니다.
4. **AI 검수 시작**은 한 번에 최대 20개 발언을 순차 처리합니다. 각 대상의 앞뒤 2개 원문 채팅을 맥락으로 포함합니다. 이모티콘은 검수 대상에서 제외합니다. 검토 필요·맥락 부족·지적 없음은 AI 의견이며 사람이 직접 문제 있음·문제 없음·미확정으로 판단합니다.
5. **앞뒤 대화·메모**에서 원문 앞뒤 5개와 기준을 확인하고 메모를 남깁니다. **원문에서 직접 검토할 발언 고르기**는 AI 없이 사용 가능합니다. 아이디 버튼으로 해당 사용자의 발언을 모아볼 수 있습니다.
6. 완료한 구간은 즉시 브라우저에 저장됩니다. 중단·실패 후 같은 제공사·기준으로 재실행하면 완료된 발언을 건너뜁니다. 기준이나 제공사가 바뀌면 다시 검수합니다. 재검수는 최신 AI 의견을 덮어쓰며 사람의 판단과 메모는 보존합니다.
7. **검색 결과 CSV**는 검색된 원문 전체, **검수 결과 CSV**는 모든 검수 결과·원문·이유·메모·기준·모델을 저장합니다. 표의 페이지 수와 무관하며 UTF-8 BOM과 수식 이스케이프를 적용합니다.

## AI 연결과 데이터 처리

- 기본 모델: Gemini `gemini-3.5-flash-lite`, OpenAI `gpt-4.1-mini`. 모델 목록은 `app/lib/chat-review.ts`의 `PROVIDERS`에서 관리합니다. 제공사별 공식 구조화 출력 API를 사용하고, 누락·중복·존재하지 않는 발언 ID 또는 미완료 응답은 실패로 처리합니다.
- 공개 `/api/chat-inspector/review`는 요청자가 입력한 키만 사용합니다. 사이트의 `GEMINI_API_KEY`나 `OPENAI_API_KEY`로 대체하지 않으므로 사이트 소유자의 공용 키가 무제한 사용되지 않습니다. 새 환경변수 설정 없이 배포할 수 있습니다.
- 키는 비밀번호 입력란과 페이지 메모리에서만 유지합니다. 제공사를 바꾸거나 페이지를 닫으면 지워집니다. IndexedDB/localStorage/URL/애플리케이션 로그에 키를 저장하지 않습니다. HTTPS로 사이트 서버를 거쳐 선택한 제공사의 고정 API 호스트에만 전송합니다. 프록시 요청 본문을 기록하는 외부 모니터링을 별도로 활성화하지 마세요.
- 아이디·닉네임 필드는 임시 발언자 이름으로 바꿔 AI에 전송합니다. 본문에 포함된 이름 등은 원문 그대로 전송되며 UI에서 안내합니다. OpenAI에는 `store: false`를 지정합니다. 제공사의 자체 데이터 보관 정책까지 제어하는 것은 아닙니다.
- ChatGPT/Gemini 앱 구독과 별도의 API 키 및 제공사 사용 한도가 필요합니다. 사용자 동작 없이 호출하지 않으며 유료 요청을 자동 재시도하지 않습니다. 중지는 후속 구간 전송을 멈추지만 이미 제공사가 처리 중인 요청의 과금을 취소한다고 보장하지 않습니다.
- 서버는 JSON 본문 350KB, 최대 100개 입력 행(대상 20개), 행당 4,000자, 전체 행 JSON 90,000자, 기준 2,000자, 연결 50초를 제한합니다. 리디렉션 금지, 교차 출처 브라우저 요청 차단, `no-store`, 정제된 오류 메시지를 적용합니다.
- 채팅 안의 지시문을 실행하지 않도록 지시하며, 외부 도구 실행·자동 제재·전송 기능은 없습니다. 영상·음성을 분석하지 않고 제공된 주변 대화만 참고하므로 AI의 지적 없음은 문제 없음 확정이 아닙니다.

## 기록 및 저장

- 공개 XML의 일반 채팅, 이모티콘, 사용자 ID와 텍스트가 있는 후원 이벤트를 가져옵니다. 빈 시스템 이벤트는 제외합니다. 삭제·비공개·인증 제한은 우회하지 않습니다.
- 영상 시간은 파일별 상대 시간에 앞선 영상 길이를 더합니다. 날짜·시각(KST)은 각 파일 시작 시각에 더한 추정값이며 파일 시작 정보가 없으면 미제공으로 표시합니다.
- 접속 suffix `(숫자)`를 제거한 ID로 그룹화하되 원본 ID와 각 발언의 닉네임은 보관합니다. 동일 시각에 반복한 동일 발언도 개별 메시지로 유지합니다.
- 원문·검수 결과는 방문자별 IndexedDB에 저장하며 기기 간 공유하지 않습니다. 기존 DB 구조에 선택적 검수 필드를 추가하여 기존 VOD 기록과 호환됩니다. 브라우저 저장 실패 시 경고하며 CSV로 보관할 수 있습니다.
- VOD 메타데이터는 30초 캐시, 조회는 지정 SOOP 호스트만 허용(12초/8MB 제한), 공개 조회 형식 변경 시 연동 수정이 필요할 수 있습니다.

## 검증

- `node --experimental-strip-types --test tests/chat-inspector.test.mjs tests/chat-review.test.mjs`: VOD 경계·중복 보존·CSV, 검수 분할·맥락·임시 이름, 응답 누락/중복/위조 거부, 제공사별 요청·응답 형식, 오류·입력 크기·출처 검사.
- AI 어댑터 테스트는 모의 응답을 사용합니다. 실제 키를 이용한 유료 모델 호출 및 판정 품질 평가는 별도로 필요합니다.
- `npm run build`: Next.js 배포 빌드. 제한된 로컬 Windows 환경에서 Turbopack 자식 프로세스 또는 기존 출력 폴더 권한 문제 시 별도 출력 폴더의 `next build --webpack`으로 확인합니다.
